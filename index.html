アプリについて

WINDOWS

Windows版

ABEMAのリアルタイムコメントをWindowsで快適に 閲覧・投稿できる、多機能コメントビューアです🐸

主な機能

  • リアルタイムコメント表示
  • コメント投稿
  • ログ保存・検索
  • コメント追随機能
  • マルチビュー（タブ形式）
  • 番組分析（ランキング・投稿回数分布・推移グラフ）

動作環境

Windows 10 / 11
インストール不要のポータブル版です。

ANDROID

Android版

ABEMAのリアルタイムコメントをAndroidで快適に 閲覧・投稿できる、モバイル用コメントビューアです🐸

主な機能

  • リアルタイムコメント表示
  • コメント投稿
  • コメント追随機能
  • 通信節約機能
  • 画面焼け対策

動作環境

推奨：Android 12以降

Android 11以前では、端末のWebView / Chrome環境によって、 トークンを取得できない場合があります。 古い端末でも動作する可能性はありますが、動作保証はありません。

動作確認：Pixel 9aなど。
タブレットモードは、現在は基本未対応です。
本アプリは縦画面専用です。

Windows版 2.30をダウンロード（ZIP）

導入方法

ZIPファイルをダウンロードして展開し、 展開先にある ABEMA Comment Viewer RT.exe を起動してください。 インストールは不要です。

Ver.1.10以前から更新する場合

既存フォルダへ上書きせず、新しいフォルダへ展開してください。

  • 保存先が Windows AppData の場合は、同じWindowsユーザーであれば設定・トークン・ログが自動で引き継がれます。フォルダのコピーは不要です。
  • 保存先が ポータブル（アプリと同じ場所） の場合は、以前のフォルダから settings、token、必要に応じて log をコピーすると引き継げます。

保存先は旧バージョンの「設定 → 保存先設定」で確認できます。詳細はZIPに同梱の 更新方法.txt を参照してください。

インストール方法

  1. Android端末でAPKをダウンロードします。
  2. Androidの設定で、APKを開くアプリに対して 「不明なアプリのインストール」を許可します。
  3. ダウンロードしたAPKを開き、インストールします。

ダウンロード時の警告について

Chromeなどで「危険なファイルの可能性があります」といった 警告が表示される場合があります。 Google Playストア外で配布しているAPKでは、 このような警告が表示されることがあります。
